Implemented Code navigation

  • K304.1.1 — allowances, minimum selected wall, dimension control.
  • K304.1.2 Eq. (34a) — 2024 OD/minimum-wall internal-pressure calculation.
  • Eq. (35a) — inverse pressure-rating QA for selected minimum wall.
  • K304.8.3 Eq. (37) — straight-pipe inside-surface pressure stress intensity.
