# KD-3 Qualification Oracle R1

This directory is a qualification-evidence workspace. It is **not** a production KD320 implementation.

## Authority boundary

```text
native CORE KD320 = NOT QUALIFIED / BLOCKED
production equation authorization = false
Code compliance = false
design authority = false
```

The public ASME product pages in `source-ledger.json` establish only edition/scope identity. Exact KD-3/KD320 semantics and fatigue-curve custody must come from the controlled licensed source and are deliberately left pending.

## Files

- `source-ledger.json` — source identity, admissibility and license boundary.
- `requirements.json` — G0-G6 / E01-E12 qualification requirements.
- `catalog.json` — immutable benchmark/admission matrix.
- `scripts/audit-b313-ch9-kd3-oracle.mjs` — fail-closed catalog/source/coverage audit.
- `scripts/solve-b313-ch9-kd3-qualification-foundation.mjs` — independent foundation arithmetic only.

## Admission rule

A pending native case may not acquire expected `Seq`, fatigue life `N`, curve points or correction parameters until an independent oracle is admitted with source/reference custody. Expected values must never be generated by the production implementation under test.

## R1 case coverage

R1 reserves cases for zero/tensile/compressive mean stress, stress-pair permutation and near-degenerate states, exact/interpolated/out-of-range fatigue-curve behavior, material/temperature boundaries, Miner arithmetic, applicability and edition/missing-input blocks, a primary published numerical example, and an independently checked project-style calculation.

Only independent thick-cylinder Salt and Miner bookkeeping cases execute in R1. Native KD320 cases remain data slots with `expected = null`.
