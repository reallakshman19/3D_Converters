# GC-PW A3-U2 — first executable Preview → attested Weight integration session

**Status**: Integrator-owned XML-CII domain session, not a new contract-only fixture. Parent #999, #921, and #1030. Ground contract GC-PW/1.0, coding protocol Common V3.2.

## Actual merged modules invoked in order

1. \`createPreviewBasis\` from \`tabs/xml-cii-2019-standalone/ui-adapted/xml-cii-adapted-preview-facts-basis.js\`. Uses loaded source text (not filename/length), master rows and field mapping content, revisions, selected scope, staged source and config/overrides. Output \`basisId\` is a full-content digest. \`assertBasisDigest\` from the shared conformance contract independently validates this digest.
2. Caller supplies \`loadFactPages({basis, requestId, report, isCancelled, sourceRefs})\`, the producer port for the **future actual Preview worker-backed read-model**. There is deliberately NO synchronous legacy geometry fallback or automatic derived “facts” generated by this integrator. The callback must return full \`Page<FactRecord>[]\` from authoritative producer. An absent, failed, delayed or cancelled callback is not considered a ready Preview.
3. \`verifyPhysicalFactPages\` from merged \`contracts/gc-pw-v1/occurrence-bridge.mjs\` is run against the actual revisited live source/master bytes, an independently enumerated original source population, physical source occurrences and required field IDs. Reject original→physical mismatch, truncated paging and source revision changes. Source ordinals and signature constitute the full identity; no NodeNumber=-1 or row index guessing.
4. \`createAttestedWeightReviewService\` from merged \`converters/xml-cii2019-core/weight-facts-attested-session.js\` receives fully validated \`toWeightFacts\` read-only FactRecords together with source/master/selection/staged/config/override **text bytes** and independently selected physical occurrence IDs. Its internal SHA checks run a **second separate attestation** before \`openBasis\` can occur. The scorer is the existing \`createXmlCiiFactWeightScorer\` from merged Agent-W, with no alternative Rating/bore/geometry authority introduced.
5. \`awaitReady()\` returns the genuine Weight review service **only after** the attested job event is \`completed\`. Its \`getFacts\`, \`getProposals\`, \`applyDecisions\`, \`freezeSnapshot\` are the real merged service operations. Proposals do **not** create decisions; callers must explicitly submit CAS commands with the current source and revision. Cancellation or producer errors produce a typed failure and do not expose an accepted session.

## Safety and acceptance limitations

This adapter is **runtime-capable** but is *not yet plugged into the actual Preview UI or existing master worker*. The full-population callback must later be supplied by a real producer, not by a synthetic test callback. Without one the adapter throws \`MISSING_WORKER_PRODUCER\`. It does NOT claim that the old 1.06-second browser long task or stranded spinner on rejected staged JSON is fixed, that the owner's private 385/10699/383/1595 inputs have been exercised, or that original PL01/PL06 source→CII accuracy is established.

An independently enumerated source original occurrence list (e.g., produced by merged #1008 source custody) must be provided by the caller. A synthetic expected count copied from the output would still be fraudulent even if shape checks pass. The adapter does not create that ground truth itself. Final Mass Check #1021 and J05 Material/B31.3 remain separate independent release gates.
