# ASME B31.3 Material Factor Master and Pipeline

Target edition: **ASME B31.3-2024**. Public edition status checked 2026-08-10. The canonical project file is `docs/Masters/b313-material-factor-master.json`; browser runtime data is generated by `scripts/generate-b313-material-factors.mjs`.

## Families and identity

Canonical routing families are `CS`, `LTCS`, `SS`, `DSS`, `SDSS`. `LT`, `LT CS`, and “low temperature carbon steel” normalize to `LTCS`. Initial project identities are A106 Gr B, A333 Gr 6, A312 TP304, A312 TP316, A790 UNS S31803, and A790 UNS S32760. Identity is sourced from existing project piping-class masters and is independent of factor qualification.

## Factor authority

`S`, `E`, `W`, and `Y` are independently status-qualified. Default `strict` mode accepts only `VERIFIED` and `PROJECT_APPROVED`. `benchmark` additionally permits `BENCHMARK_ONLY`; `screening` can permit explicit `SCREENING` rows. No family-level numeric default is silently substituted.

The initial A106 Gr B temperature `S` series supplied during this work is stored as `BENCHMARK_ONLY`. The supplied DN benchmark provides `E=1`, `W=1`, `Y=0.4` at 0 °C only, also `BENCHMARK_ONLY`. LTCS/SS/DSS/SDSS identities are wired but intentionally return `B313_FACTOR_DATA_INCOMPLETE` until controlled factor data is loaded or the caller supplies explicit overrides.

## Public API

```js
import {
  normalizeB313MaterialFamily,
  resolveB313MaterialIdentity,
  resolveB313DesignFactors,
  getB313MaterialFactorCoverage,
  calculateB313MaterialDesign,
} from './converters/b313-material-factors/index.js';
```

`calculateB313MaterialDesign()` performs material identity -> `S/E/W/Y` -> B31.3 straight-pipe calculation -> Pipe Wall Master selection. Pipe-wall selection requires explicit `dimensionStandard`; material family never silently chooses B36.10M or B36.19M.

## End-to-end benchmark

A106 Gr B, 0 °C, 51.1 barg, OD 273 mm, C=6 mm, `E=W=1`, `Y=.4`, and 12.5% negative tolerance yields required nominal wall `12.553618958106954 mm`. The merged project Pipe Wall Master selects `12.7 mm`, preferred Sch 60, equivalent `60 / XS`.
