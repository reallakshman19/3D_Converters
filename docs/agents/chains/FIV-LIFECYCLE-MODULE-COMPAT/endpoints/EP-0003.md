## Defect disposition

Current project schema source exports both post-PR720 lifecycle APIs. The user-visible FIV startup error was a module-link compatibility failure: newer consumers named-imported post-PR720 APIs from an unversioned schema URL, allowing a stale pre-PR720 browser module to abort the whole ES-module graph.

The repair routes lifecycle schema access through `tabs/vibration-project-schema-compat.js`, which:

- namespace-imports a cache-busted schema URL;
- resolves lifecycle APIs at invocation rather than at ESM named-import link time;
- fails closed with `VIBRATION_PROJECT_SCHEMA_LIFECYCLE_API_UNAVAILABLE` when a required API is genuinely absent;
- does not synthesize lifecycle data or change project, screening, numerical, or engineering authority.
