## Exact-current diagnosis

1. Regex smart suggestions expose a composite confidence score. For Line Key the score is `0.72*exactMasterRate + 0.16*uniqueness + 0.18*lineShape - widthPenalty`; the UI renders that score as a bare percentage, while exact-master coverage is only embedded in evidence text. This makes a confidence percentage easy to misread as a match percentage.
2. The interactive Regex Tester sample selector renders every branch sample even though the core already detects multiple formats. Selection should be presentation-bucketed by structural signature with a representative and count; extraction itself must still run on the full sample set.
3. Branch Auto-Suggest currently accepts only exact boundary-safe loaded keys. Structurally related tokens such as `P4110010` cannot resolve to a loaded family key even when progressively masking the suffix yields exactly one authoritative Line List key.
4. Any family inference must fail closed on ambiguity. With loaded `[P4110001, P4110003]`, mask `P41100XX` is ambiguous and must not select one. `B4110004` must not silently become a P-family key.
5. Apply Pattern already checks final exact Line List membership, but the `$1/$2` replacement semantics are under-explained. Auto Detect currently reports HIGH/MEDIUM/LOW without exposing the threshold basis next to exact coverage.

## Protected invariants

- Loaded Line List membership remains final mapping authority.
- Exact boundary-safe branch match outranks family inference.
- Progressive family inference can assign only if the most-specific candidate level yields exactly one loaded key.
- Regex/family evidence never persists a key that is absent from the loaded Line List.
- Representative sample bucketing is UI-only and must not alter extraction/coverage calculations over the full sample set.
- No B↔P designator rewrite without explicit governed configuration.

## Validation plan

- Independent arithmetic: 50% exact Line Key master coverage + 100% uniqueness + 100% line-shape => 70% composite confidence; UI must expose both 50% and 70% distinctly.
- Pattern confidence thresholds: 6/10 exact => LOW; 7/10 with >=2 exact => MEDIUM; 19/20 with >=2 exact and >=2 distinct => HIGH.
- Representative buckets: counts sum to all unique branch samples and one representative is exposed per structural signature.
- Family resolver: unique `P41100XX` authority maps; two loaded survivors block ambiguous; B/P negative blocks; exact match remains first authority.
- Apply Pattern: `$1` replacement is explained and a non-loaded result is rejected.
