## Completed this leg

Added `converters/engineering-calculations/bolts/detailed-friction.js` with four explicit reference capabilities:

1. `calculateLegacyThreadGeometry()`
   - reproduces the displayed `Bolt Torque Calc.xls` geometry relationships;
   - supports explicit thread starts through `lead = starts * pitch`;
   - returns pitch diameter, minor diameter, tensile-stress area and helix angle;
   - remains non-authorizing.

2. `calculateBearingFrictionRadiusUniformWear()`
   - implements the legacy workbook displayed arithmetic bearing radius `(do + di) / 4`;
   - labels the assumption explicitly.

3. `calculateDetailedFrictionTorque()`
   - exact V-thread tightening reference based on NASA RP-1228 friction/helix coupling;
   - separates pitch mechanical torque, thread torque, thread friction/coupling increment, bearing torque and total torque;
   - accepts explicit thread friction, bearing friction and bearing friction radius;
   - reports an effective K only as a derived diagnostic, not as the primary model input;
   - fails closed if the friction/helix denominator is non-positive;
   - `canUseForDesignAuthority=false`.

4. `calculateLegacyLinearizedDetailedTorque()` and `calculateLegacyWorkbookDetailedAssembly()`
   - preserve the workbook's displayed additive/linearized relation separately from the exact V-thread relation;
   - expose exact-vs-legacy difference without calibrating either result to the other.
