## Source qualification result

The previous source hard stop is sufficiently cleared for a **reference/non-authorizing** implementation by combining two independent pieces of evidence:

1. The owner-supplied legacy `Bolt Torque Calc.xls` exposes a human-readable equation banner in the workbook binary containing the intended geometry and linearized torque decomposition:
   - `H = p cos a`;
   - effective/pitch diameter `Es = D - 0.75 H`;
   - minor diameter `Ks = D - 17 H / 12`;
   - tensile stress area `As = pi (Es + Ks)^2 / 16`;
   - `tan(lambda) = p / (pi Es)` for a single-start thread;
   - torque proportional to preload times the sum of pitch/lead, thread-friction and bearing-friction terms, with explicit thread and bearing friction coefficients and explicit inner/outer nut-bearing diameters.
   The workbook expression is linearized: the thread term is the sum of lead and flank-friction contributions and does not show the exact friction/helix coupling denominator.

2. NASA Reference Publication 1228, *Fastener Design Manual* (1990), provides a controlled public detailed V-thread torque relation through the torque coefficient:
   `K = (dm / (2 d)) * (tan(psi) + mu sec(alpha)) / (1 - mu tan(psi) sec(alpha)) + 0.625 mu_c`, with separate thread and bearing friction coefficients. The implementation will generalize the bearing term to an explicit bearing friction radius rather than assuming `0.625 d`.

This is adequate to code two explicitly separate calculations:

- exact V-thread friction reference model using the NASA friction/helix coupling denominator;
- legacy-workbook linearized comparator using the workbook's displayed additive equation and explicit arithmetic-mean bearing radius `(do + di)/4`.

Neither model is Code/design authority. VDI 2230 / ISO 16047 project qualification, real friction data custody, tightening scatter and assembly validation remain outside this patch.
