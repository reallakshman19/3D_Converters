# AIV D.2.3 Working-Table Benchmark v1

## Purpose

This document defines the controlled UI input fixture used by the AIV qualification workspace for `Load EI D.2.3`.

The fixture exists to exercise the same **Sources / Assessments / Source→Assessment** working-table path that future project evidence will use. It is not a production AIV calculator and does not authorize benchmark calculation, screening, or design use.

## Modified-input behavior

Immediately after `Load EI D.2.3`:

```text
benchmark input status = CONTROLLED_INPUT_REFERENCE
```

Any visible working-table edit, row addition/deletion, or replacement import marks the loaded benchmark modified:

```text
benchmark input status = NOT_APPLICABLE_MODIFIED_INPUTS
```

Published references remain visible as the original controlled-case reference. Reloading EI D.2.3 restores exact benchmark-input identity.

## Readiness behavior

Readiness serializes and reparses the **current visible table cells** and joins them to the current topology input. It does not consume hidden immutable benchmark objects behind the operator's edits.

For the unmodified relief relationship, the intended non-numerical readiness outcome is:

```text
status                        READY_FOR_QUALIFICATION
requestPrepared               false
numericalExecutionAuthorized  false
physicalDistance              0.8 m
pathStatus                    RESOLVED
topology physical distance    null / not derived
```

## Explicit non-goals

This slice does not implement:

- source-PWL equations;
- pressure conversion logic;
- sonic-state resolution;
- attenuation;
- simultaneous-source logarithmic combination;
- T2-6 calculations;
- LOF calculation;
- line-summary aggregation;
- pass/safe classification;
- BENCHMARK_ONLY or SCREENING numerical execution.

Those remain later roadmap stages after the required human engineering reconciliation and promotion gates.
