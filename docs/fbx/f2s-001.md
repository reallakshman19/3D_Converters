# F2S-001 FBX → StagedJSON

This converter accepts binary FBX bytes and an external `FbxStagedMapping.v1` manifest. Parsing is performed by a Web Worker using the committed `ufbx` WebAssembly build. No runtime network access or CDN dependency is used.

## Authority boundary

Only manifest entries with `componentType: "PIPE"`, `scopeDisposition: "promote"`, exactly two exact geometry port references, and complete explicit symmetric connectivity are published. Names and hierarchy labels remain evidence and never classify components. Missing or incomplete mapping authority returns `BLOCKED_MAPPING` and does not publish a `.staged.json` artifact.

The four identity domains remain separate:

- FBX source object ID (`sourceObjectId`)
- FBX geometry resource ID (`geometryObjectId`)
- FBX scene occurrence ID (`sourceOccurrenceId`)
- logical engineering component ID (`logicalComponentId`)

## Parser provenance

- Upstream: `ufbx/ufbx`
- Revision: `729ab835444f5f229e5f7cff332692ce6c00415d` (`v0.18.0` integration)
- License: MIT alternative retained in `third_party/ufbx/LICENSE`
- Hashes: `third_party/ufbx/provenance.json`
- Rebuild: `CC=clang-18 WASI_SYSROOT=/usr bash scripts/fbx/build-ufbx-wasm.sh`

The parser loads the source scene without conversion for evidence, then loads the same bytes through ufbx's right-handed Y-up, millimetre normalization path. Source and normalized geometry/transforms are retained together. Unsupported inheritance, shear, singular transforms, and ambiguous non-uniform scale block publication.

## Validation

```text
node tests/fbx/run-all.mjs
node tests/fbx/test-determinism.mjs
node tests/fbx/test-registry.mjs
node tests/fbx/test-static-guards.mjs
```

The mapped purpose-built fixture contains two mesh occurrences in centimetres. One occurrence is parented, proving parent composition; the mapping connects their exact mesh vertices explicitly. A second Z-up binary fixture proves axis conversion, centimetre-to-millimetre normalization, parent composition, and FBX geometric translation. The project-file proof is recorded in `docs/fbx/project-proof.json` without committing the project FBX.
