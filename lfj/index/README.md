## U01 contract and source custody

`streamJsonOccurrenceEvents(snapshot,{sourceRefId,onEventPage,pageEvents=256,pageBytes=65536,maxOccurrences=2000000,signal})` takes an exact R03 source snapshot plus **a caller-supplied, stable original source reference** (e.g. a PL01 engineering file identity). That source reference is distinct from LFJ's content-addressed `sha256:...` ID and **must not automatically substitute for GC-PW `sourceId`**. The R04 parser receives original bytes and validates the entire JSON grammar on this revision.

The sink `onEventPage` MUST be a callable function: each bounded frozen page contains `OPEN` value events in **original source order** and `SEAL` events after the corresponding scalar/composite closes. An `OPEN` carries `occurrenceId`, zero-based `ordinal`, RFC6901 path, `parentId`, `type`, `startByte`, `sourceSha256`, `sourceRevision`, `sourceRefId`; `SEAL` carries original byte `endByteExclusive` against the same identity. Every JSON **value**, not just selected top-level branches, is visited: objects, arrays, strings, numbers, boolean, null and all descendants. Keys are property names/pointer segments, **not separate JSON value occurrences**.

Identity is JSON-safe `JSON.stringify(['lfj-json-value/v1',sourceRefId,sourceRevision,escapedPointer])`, not a physical component identity. `engineeringReady:false`, `rightsBasis:'SOURCE_FACTS_ONLY'`; neither `BasisRef` nor `physicalOccurrenceId` nor frozen `RigidMatch1`/`Rigidmatch2` are produced by this module.

Working memory is bounded by the R04 maximum grammar depth and R05 event-page count **multiplied by the maximum retained pointer size**, not all original source values. Every JSON Pointer has a hard **65,536 UTF-16-code-unit limit**; longer valid nested JSON member paths fail closed with typed `POINTER_LIMIT` before any oversized event is emitted. This explicit limit prevents quadratic retained-path amplification in otherwise valid deeply nested long-key JSON. A fixed event *count* is not a measured byte/heap bound; real browser memory and throughput remain separate R06–R18 acceptance vetoes. The index has no default in-memory collector. A receiving storage port may persist provisional events, but must **commit only after** the returned `LFJ.JSON.OccurrenceIndexSummary.v1` has `complete:true` and matching source SHA/revision. A thrown parser/sink error never returns a complete summary; U04 will separately govern persisted rollback/epoch staleness. The default page size is 256, hard max 4096, original value budget 2,000,000, enforced before emission.

## Release vetoes after R05

The R05 port emits provisional bounded pages: the caller MUST persist them transactionally and commit only after the returned COMPLETE summary, matching original bytes/revision and caller's current epoch. R05 cannot roll back an arbitrary external storage system after its callback throws. Durable storage, Worker lifecycle and stale-run commit fencing remain R06–R10 obligations, not falsely accepted by in-process R05. R12–R19 own exact three-repo engineering integration, including the legacy Resolver ancestor-owner defect; R18 owns actual populated 30/90MB reference-device browser memory/latency and independent writer-produced XML/CII and source-to-output goldens. **No Preview, Weight or CII writer product source was changed.**
