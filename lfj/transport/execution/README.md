## U01 new Worker-only admission seam

`runRequiredWorkerJob({createWorker,trustedWorkerCtor,jobId,sourceRefId,sourceRevision,sourceSha256,byteLength})` requires an **actual platform-trusted Worker constructor** at the application composition root, not a same-thread Worker-shaped inline callback. The browser defaults to its native `globalThis.Worker`; Node WorkerThreads callers explicitly pass `trustedWorkerCtor: Worker` from `node:worker_threads`. Method-shape and echoed `READY` are insufficient; the created object must also be `instanceof` that trusted constructor. The constructor/`createWorker` injection is a **trusted application configuration boundary** and must never be built from untrusted source data; fake constructors supplied by an adversary are not an isolation guarantee. A missing/null/throwing factory rejects `WORKER_UNAVAILABLE`; a synchronous function posing as a Worker fails `INVALID_WORKER_PORT` **before postMessage is invoked**. The port must have asynchronous `message`/error subscription, `postMessage` and `terminate`; it supports browser Worker event listeners and Node WorkerThreads `on/off`. It sends versioned `LFJ.WorkerExecution.v1` `START`, receives matching `READY` with **the same job and source metadata** or fails `WORKER_PROTOCOL`; a hung admission times out rather than ever running JSON on the caller thread. Caller remains responsible for Worker termination in U01; R07 governs retries, cancellation, stale jobs and disposal.

**Independent test proof:** [`required-worker.test.mjs`](./required-worker.test.mjs) committed first (RED until production `required-worker.mjs` added), plus real **native Node WorkerThreads fixture** `required-worker-fixture.mjs`. Tests assert actual `isMainThread===false` and `threadId>0` under an independently instantiated Worker, invalid source metadata fails before construction, unavailable factories and fake Worker shaped callbacks fail without inline work. [Exact Node 22/24 dedicated workflow #37801199693](https://github.com/reallaksh19/3D_Converters/actions/runs/37801199693) **PASSED both versions** at production + dedicated workflow head. This is actual Node Worker isolation in a native test, **not** a Chromium performance metric nor a universal assertion that any arbitrary injected port is truly isolated.
