## Numerical boundaries preserved

### Short form

```text
F = As * Sref * alpha
T = K * F * d
```

No K or preload fraction default is introduced.

### Detailed friction

The adapter calls the existing exact V-thread reference kernel and exposes pitch, thread, bearing and total torque separately. Effective K remains derived diagnostic output.

### Installation strength

```text
sigma = F / As
tau   = 16 T_thread / (pi d_s^3)
VM    = sqrt(sigma^2 + 3 tau^2)
```

The adapter accepts **thread torque**, not total wrench torque, for bolt-section torsion.
