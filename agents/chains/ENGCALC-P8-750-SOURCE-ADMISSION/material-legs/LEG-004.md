## Finding

The public `computeFlangeFaceBindingSourceSubmissionReviewHash()` helper previously accepted every source-register state supported by the generic sealer. Because `recordState` is intentionally excluded from the review fingerprint, a `DRAFT` or `RETIRED` record could be fingerprinted and later changed only to `INDEPENDENTLY_CHECKED`; admission would then see the same semantic fingerprint. That did not enforce the documented pre-review sequence requiring a `PROJECT_CONTROLLED` candidate.

## Repair

- `computeFlangeFaceBindingSourceSubmissionReviewHash()` now requires `recordState === PROJECT_CONTROLLED` after existing v1 shape/seal validation.
- Admission does not call the public pre-review helper. It recomputes the same state-independent projection internally after requiring `INDEPENDENTLY_CHECKED`.
- Tests now reject pre-review fingerprinting for `DRAFT`, `INDEPENDENTLY_CHECKED`, and `RETIRED` records.
- The pre-review CLI is explicitly negative-tested with a `DRAFT` record.
- The generic source-register/sealer remains unchanged.
